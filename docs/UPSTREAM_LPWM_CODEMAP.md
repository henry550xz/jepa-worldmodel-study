## One Gaussian PushT training batch
1. `train.py:Trainer.__init__` seeds through `utils.seed`, calls `datasets.pusht_dset.load_pusht_slice_train_val`, and creates Accelerate dataloaders. That loader opens separate `pusht_noise/train` and `pusht_noise/val`; its `split_ratio` argument is unused.
2. `PushTDataset.__init__/get_frames` read `states.pth`, `rel_actions.pth`, `velocities.pth`, `seq_lengths.pkl`, optional `shapes.pkl`, and `obses/episode_NNN.mp4`. State is raw `[pusher_x,pusher_y,block_x,block_y,angle,pusher_vx,pusher_vy]`; proprio is normalized pusher position/velocity. Relative actions are divided by 100, then standardized using fixed ACTION_MEAN/STD. State itself is not standardized by the dataset.
3. `TrajSlicerDataset.__getitem__` reads 20 raw frames for num_hist=3, num_pred=1, frameskip=5. Observations/state select raw offsets 0,5,10,15. Actions are concatenated into four 10-dimensional groups, not averaged. Batched visual shape is `(B,4,3,224,224)`, action `(B,4,10)`, proprio `(B,4,4)`, state `(B,4,7)`. Fourth action group is loaded but unused by the training predictor. Slice order is permuted once; DataLoader uses shuffle=False.
4. `datasets.img_transforms.default_transform` resizes, center crops, normalizes RGB from [0,1] to [-1,1]. `VWorldModel.encode_obs` flattens B*time and calls `ViTEncoder`; its scratch encoder transform is identity.
5. `models.vit_encoder.ViTEncoder.forward`: 14x14 stride-14 Conv2d patchification of 224x224 -> 256 spatial tokens plus CLS. Width 384; 12 noncausal spatial Transformer blocks; 3 heads, dim_head=64, MLP width 768. CLS output enters `MLP` projector (hidden 2048, LayerNorm) -> one 384-dimensional token. Reshape gives raw `u: (B,4,1,384)`.
6. `VWorldModel._forward_adaln`: Gaussian `Link(identity)` gives z=u. `Embedder` encodes each 10-vector of grouped actions to 384 (`conf/action_encoder/lewm_embedder.yaml`, mlp_scale=4). Proprio encoder is instantiated but does not condition the AdaLN path.
7. Predictor sees ONLY `z[:,:3]` and action embeddings `[:,:3]`; target is `z[:,1:]`. Thus all three shifted next-step pairs are supervised (0->5,5->10,10->15), not just the last pair. No future observation is passed into the temporal predictor. All frames do get encoded to construct the targets.
8. `ARPredictor.forward` adds temporal position embeddings; its six `ConditionalBlock`s use causal temporal attention and per-frame action-conditioned AdaLN shift/scale/gates. Heads=16, dim_head=64 (attention inner width 1024, not 384), MLP=2048, dropout=0.1; final projector hidden=2048 -> `(B,3,1,384)`. Attention uses PyTorch scaled_dot_product_attention. AdaLN modulation is zero-initialized: action sensitivity can be exactly zero before initial updates. This is expected; test action influence after warmup, without altering initialization.
9. `VWorldModel._forward_adaln` computes mean latent MSE between linked predictions and shifted targets. `detach_target=False`: prediction AND target branches backpropagate into the SAME encoder. There is no EMA/teacher encoder on this path. Distribution reference samples are detached; they are not a target encoder.
10. `RDMReg.reg_loss`, `swd`: p=2 samples unit-variance Gaussian reference vectors; identity link retains them. agg=b reshapes `(B,4,1,D)` to `(B,4,D)`: sorting is over B independently at each time/token, not pooled over time. 8192 random unit directions project features/reference; mean squared differences of sorted projections estimate squared sliced Wasserstein-2. Regularization covers all four observed frames. Official selected cell uses `loss = z_loss + 0.5*reg_loss`; optional variance/covariance terms are zero.
11. `Trainer.init_optimizers/train`: separate encoder, predictor and action/proprio optimizers; accelerator.backward(loss), then steps. Selected reproduction enables `models.mup.mup_init_` on scratch encoder/predictor and `mup_param_groups` with base LR 1e-4, base width 384, weight decay .01, AdamW eps=1e-15. Matrix LR is base_lr*384/fan_in; vector LR is base_lr. Action/proprio modules use muP parameter groups but are not included in the fresh muP initialization calls. State labels never enter this training objective.

## One sparse PushT batch
The same batch, normalization, encoder, actions, temporal predictor, targets and optimizers apply. Set link=reprelu, target_p=1, mu=0. `Link` is shared on encoder and predictor outputs. `reprelu(x)` has ReLU forward values and GELU surrogate derivatives (`relu(x).detach()+gelu(x)-gelu(x).detach()`); it preserves zeros while allowing gradients below zero. There is no learned threshold in this Link class. RDMReg samples unit-variance Laplace (scale 1/sqrt(2)), then applies the same rectifying link to its detached reference. The rectified reference is not zero-mean/unit-variance after rectification. No assumption of realized sparsity is warranted before measuring it. Gradients reach both online source/target encoder paths, predictor and (after AdaLN gates learn) action embedder.

## Decoder does not make an observation baseline
`VWorldModel._forward_adaln` optional decoder uses `z_emb.detach()` and reconstructs CURRENT observed frames; it never supplies temporal pixel loss to the predictor. The concat path `VWorldModel.forward` also passes `z_pred.detach()` to the decoder and detaches reconstruction inputs. `has_decoder=True` alone therefore fails the requested gradient path. A separate study subclass must decode the predicted future z WITHOUT detach and optimize future pixels, not latent MSE.

## Planning trace
- `plan.py:planning_main/load_model` restores saved `hydra.yaml` and pickled checkpoint modules, loads validation trajectories, creates PushT vector environments. PlanWorkspace prepares single-frame initial and goal observations, not a full three-frame observed history. Dataset goals are generated by simulator replay over frameskip*goal_H raw actions.
- `planning.cem.CEMPlanner.plan` preprocesses current/goal RGB; `encode_obs_linked` encodes the goal into the SAME linked space as rollouts. Action tensors are normalized grouped actions `(N,H,10)`.
- `CEMPlanner.init_mu_sigma`: initial mean zero unless warm-started, standard deviation var_scale=1. Each iteration samples 300 candidates per evaluation trajectory and inserts the current mean as candidate zero. No explicit candidate clipping appears here.
- `VWorldModel._rollout_adaln` encodes initial observation(s), embeds the whole proposed action sequence, and repeatedly calls `_predict_next_adaln`. Last min(num_hist,L) linked frames and aligned actions condition the next prediction; only the last predictor output is appended. H actions with one initial observation produce H+1 linked frames. After warmup the context has at most three frames, often predicted rather than observed.
- `planning.objectives.create_objective_fn(mode='last')` scores terminal linked visual MSE to the goal. Proprio is absent for AdaLN; alpha is inert. This is NOT a common physical-state score across arms.
- CEM chooses 30 elites, replaces mean/std with their statistics for up to 30 iterations; returns mean actions, not the best sampled candidate. `eval_every=1` invokes real simulator evaluation of mean actions inside optimization and permits early exit when ALL evaluation trajectories succeed. This affects compute and uses simulator feedback; retain only for labeled official reproduction.
- `planning.mpc.MPCPlanner.plan` executes an action prefix, evaluates accumulated actions by replay from original initial states, records success, uses the last observed frame for replanning and warm-starts the unused suffix. Completion is measured at prefix boundaries, not the first individual raw action that succeeds.
- `conf/plan_lewm.yaml`: seed=99, n_evals=50, goal_H=5, MPC max_iter=10, configured prefix=5, CEM horizon=5, samples=300, elites=30, steps=30. However `plan.py:PlanWorkspace.__init__` explicitly overwrites horizon AND prefix from goal_H. With frameskip=5, one model action is five simulator actions; default prefix is 25 raw actions and maximum execution is 250 raw actions. These are not 5 and 50 raw actions.
- `PushTWrapper.eval_state` reports success when joint 4D position norm <20 and wrapped angle error <pi/9; its state_dist is raw full-state Euclidean distance and mixes position, radians and velocity. This goal-state criterion is distinct from the underlying environment's fixed-target coverage reward. Study metrics separate units and must name the success definition.

## Reproduction hazards
`Trainer.save_ckpt` pickles modules plus encoder/predictor optimizers but omits action-optimizer and RNG state. `init_models` reinstantiates action/proprio encoders even after loading. Exact resumed training is not assured; initial reproduction should be uninterrupted. Future study resume requires a separately tested state-dict/RNG/optimizer path, not an assumption. Never load untrusted checkpoint/pickle data.

Official planning has simulator-dependent early exit, coupled horizons and unit-mixed state distance. Use it for reproduction, not silently as the controlled evaluator. `environment.yaml` is a long pinned Python-3.9 conda/pip export; PyPI confirms networkx==3.2.1 supports Python>=3.9 (https://pypi.org/project/networkx/3.2.1/). Keep Python 3.9 initially; dependency resolution still requires worker validation. NumPy is not explicitly pinned, so the study adds a documented NumPy-1.x compatibility constraint. No GPU or full batch was run on the controller.
